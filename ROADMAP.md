# Roadmap

shipreel's goal: **every release gets a video, with zero effort.** Ideas below are roughly in priority order. 👍 the matching issue (or open one) to vote, and PRs are welcome.

## Next

- [ ] **More templates**: gradient, glassmorphism, retro, and a "changelog card" style
- [ ] **Template gallery site** with live previews
- [ ] **Poster / thumbnail export** (PNG) next to each video
- [ ] **GIF export** for READMEs and chat
- [ ] **Per-size layout overrides** in templates (e.g. `highlight.vertical.html`)
- [ ] Monorepo support: one video per changed package, or one combined video

## Later

- [ ] **Auto-post to X / LinkedIn / Bluesky / Mastodon** from the Action, with a generated caption
- [ ] **AI-written short summaries**: turn long release notes into punchy one-liners (bring your own API key)
- [ ] **Voice-over** with text-to-speech and synced captions
- [ ] **GitLab support**: CI component plus release asset upload
- [ ] Bitbucket and Gitea / Forgejo releases
- [ ] Screenshots or short screen recordings embedded in highlight scenes
- [ ] Localized videos (multiple languages from one release)

## Done

- [x] CLI, library and GitHub Action
- [x] Keep a Changelog, conventional-changelog, release-please, changesets and GitHub release bodies
- [x] minimal, terminal and bold templates
- [x] Landscape, square and vertical exports
- [x] Custom HTML/CSS templates
- [x] Browser preview
- [x] Dogfooding: every shipreel release ships its own video

Have an idea that isn't here? [Open an issue](https://github.com/99proteam/shipreel/issues/new).
